1. Diferencia entre theme y theme.extend
 si usas theme lo que va a pasar es que por ejemplo si quiero el color rosa pastel y hay 50 más lo que va a hacer es que los 50 más lo va a eliminar y el theme.extend sirve para añadir o sea los 50 colorea mas el color que quieres agregar pero se pone que ese es el que quieres estar usando 

2. ¿Por qué bg-primary mejor que bg-[#1d4ed8]?
Porque si usas bg-primary estas declarando una sola vez el color le estas poniendo el codigo de color y ya solo vas a tener que usar ese nombre, en cambio el otro lo voy a tener que poner el codigo del color en cada cosa que quiera ese color y cuando lo quiera cambiar tengo que cambiarlo en todos lados donde este ese color
