2. Diferencia entre em y rem

rem  siempre depende del tamaño de letra del documento completo html 
em depende del tamaño de letra del elemento mismo donde lo estás usando, así que si ese elemento  un boton digamoslo asi cambia de tamaño de letra, el em cambia junto con él .
